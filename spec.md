# InvoiceCraft — API Specification

## Overview

A2MCP endpoint that accepts natural language job descriptions and returns structured invoice data + PDF. Uses x402 micropayments (0.50 USDT) on X Layer (eip155:196).

## Endpoint

### `POST /api/v1/invoice`

Generate an invoice from a natural language job description.

#### x402 Payment Flow

1. **Initial request** — Client sends `POST /api/v1/invoice` with `{ "description": "..." }`
2. **402 challenge** — Server responds `402 Payment Required` with headers:
   ```
   X-Payment-Required: true
   X-Payment-Challenge: <challenge_id>
   X-Payment-Amount: 0.50
   X-Payment-Token: USDT
   X-Payment-Chain: eip155:196
   X-Payment-Receiver: <asp_wallet_address>
   ```
3. **Payment** — Client pays 0.50 USDT on X Layer to the receiver address, with `challenge_id` in memo
4. **Retry** — Client retries `POST /api/v1/invoice` with:
   ```json
   {
     "description": "...",
     "payment_tx_hash": "0x..."
   }
   ```
5. **Fulfillment** — Server verifies the transaction, generates invoice, returns `200 OK` with invoice data + PDF

#### Request Schema

```json
{
  "description": "string (required) — natural language job description",
  "payment_tx_hash": "string (optional) — x402 payment transaction hash"
}
```

```json

  "message": "Pay 0.50 USDT on X Layer to generate invoice",

```

## Data Models

### InvoiceRequest
| Field | Type | Required | Description |
|-------|------|----------|-------------|
| description | string | yes | Natural language job description (10-2000 chars) |
| payment_tx_hash | string | no | x402 payment transaction hash |

### Invoice
| Field | Type | Description |
|-------|------|-------------|
| invoice_number | string | Auto-generated unique invoice number |
| issuer | object | Service provider identity |
| client | object | Extracted client info from description |
| line_items | array | Parsed line items from description |
| subtotal | string | Sum of line item amounts (decimal string) |
| tax_rate | string | Applied tax rate (decimal string) |
| tax_amount | string | Calculated tax (decimal string) |
| total | string | Grand total (decimal string) |
| currency | string | Always "USD" |
| due_date | string | ISO date string, 30 days from generation |
| status | string | "paid" or "pending" |
| notes | string | Payment reference notes |

## Processing Logic

### Natural Language Parsing
1. Extract client name/email from description (e.g., "invoice for Acme Corp")
2. Parse work items into line items with quantities and rates
3. Infer job type to determine reasonable pricing if not specified
4. Default: 1 item at estimated rate if quantities not given

### Tax Calculation
- Default tax rate: 8% (configurable via `TAX_RATE` env var)
- Applied to subtotal: `tax = subtotal * tax_rate`
- Total: `subtotal + tax`

### Invoice Numbering
- Format: `INV-YYYYMMDD-NNN`
- Counter resets daily
- Stored in memory (stateless — resets on restart for MVP)

### PDF Generation
- Professional layout with header, line items table, totals, payment info
- Footer: generated by InvoiceCraft, payment ref, X Layer transaction
- Font: Helvetica-based (standard PDF fonts)
- Base64-encoded in response

## x402 Implementation

### Challenge Generation
- Generate random `challenge_id` (16 bytes, hex-encoded)
- Store challenge in memory with expiry (15 minutes)
- Return 402 with challenge headers

### Payment Verification
- Verify transaction on X Layer using OKX Payment SDK
- Check: recipient address matches ASP wallet
- Check: amount >= 0.50 USDT
- Check: memo matches challenge_id
- Check: sufficient confirmations (>= 1)
- On success: generate and return invoice
- On failure: return 402 with retry guidance

## Error Codes

| Code | HTTP Status | Description |
|------|-------------|-------------|
| invalid_description | 400 | Description fails validation |
| payment_required | 402 | No valid payment provided |
| payment_pending | 402 | Tx not yet confirmed |
| payment_failed | 402 | Tx verification failed |
| parse_error | 422 | Cannot extract invoice data |
| server_error | 500 | Internal failure |

|----------|---------|-------------|
